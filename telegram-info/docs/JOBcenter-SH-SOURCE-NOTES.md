# Statewide source verification notes

The automatic Jobcenter check is deliberately stricter than housing search. Housing remains statewide and free-form; verified KdU automation is enabled only where current official values and their local scope have been confirmed.

Current official evidence includes: Jobcenter Ostholstein publishes new KdU limits effective 2026-07-01 but the table still needs import and tests; Jobcenter Kreis Segeberg provides an official Mietkostenrechner and defines the comparison as Kaltmiete plus Nebenkosten without heating; Kreis Schleswig-Flensburg currently publishes a document for appropriate accommodation costs plus a 2025 concept update, but the table still needs structured import.

Until those values are imported and regression-tested, those territories remain warning-only. This prevents a statewide scope from becoming a statewide guessed limit.
